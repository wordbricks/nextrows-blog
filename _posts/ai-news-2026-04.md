After years of falling token prices, April turned the other way at the top of the market - and showed both the power and the price of agentic AI.

## Flagship prices go up, not down (April 16 and 23)

Anthropic released Claude Opus 4.7 on April 16 at the same sticker price as 4.6 - $5/$25 per million tokens - while noting that its updated tokenizer can map the same input to more tokens, and launching "task budgets" so developers can cap token spend. A week later, OpenAI introduced GPT-5.5 at $5/$30 per million tokens with a 1 million token context, openly "priced higher than GPT-5.4," with the argument that it is more token-efficient in practice. The direction of travel at the frontier was unmistakable: better models, higher price tags, and a new emphasis on budgeting every token.

## The model Anthropic would not release (April 7)

Anthropic announced Claude Mythos Preview, a general-purpose model that is "strikingly capable at computer security tasks" - so capable that Anthropic did not release it openly. Instead it launched Project Glasswing, giving vetted partners access to find and fix vulnerabilities in widely used software. The first public result landed two weeks later: Mozilla said Firefox 150 shipped fixes for 271 vulnerabilities identified during an initial evaluation with an early Mythos Preview. Defenders, Mozilla argued, finally have the upper hand.

## Codex starts using your computer (April 16)

OpenAI's "Codex for (almost) everything" update gave the Codex desktop app background computer use on macOS - seeing, clicking and typing with its own cursor, with multiple agents working in parallel - plus an in-app browser where you can comment on pages to direct the agent. The coding agent left the terminal and started operating the same screen its user does.

## Why this month matters if you work with web data

April's lesson is discipline: token budgets, validated outputs, and the right tool per job. That is how NextRows approaches extraction - you define the schema, and the output is checked against it, so cost stays proportional to the data you actually need.
