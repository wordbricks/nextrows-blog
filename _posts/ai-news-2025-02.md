February was a month about depth: an agent that spends half an hour on one question, a model that thinks longer when the problem deserves it, and the biggest pre-training run OpenAI had ever shipped.

## OpenAI launches deep research in ChatGPT (February 2)

OpenAI introduced deep research, a ChatGPT capability that plans and executes its own multi-step web research. Ask a question and it browses for 5 to 30 minutes - reading pages, following links, reacting to what it finds - then returns a cited report. It is powered by a version of o3 fine-tuned for browsing and data analysis, and it targets work that would take a human analyst hours. It debuted for Pro subscribers, with other tiers to follow.

## Anthropic ships Claude 3.7 Sonnet and Claude Code (February 24)

Anthropic released Claude 3.7 Sonnet, which it calls the first hybrid reasoning model: one model that can answer near-instantly or spend visible, controllable thinking time on harder problems. The same announcement brought Claude Code in a limited research preview - a command-line agent that reads a codebase, edits files and runs tests on a developer's behalf. Coding agents stopped being demos this month.

## OpenAI previews GPT-4.5, its largest model (February 27)

OpenAI closed the month with a research preview of GPT-4.5, its largest model to date, scaled through unsupervised learning rather than step-by-step reasoning. The payoff is breadth: more knowledge, sharper intuition about what people mean, better writing and fewer hallucinations than GPT-4o. OpenAI was explicit that it is not a reasoning model - a signal that the field now runs on two tracks, intuition and deliberation.

## Why this month matters if you work with web data

February's agents read the web for a living. Deep research cites what it can parse, and coding agents trust structured documentation over marketing pages.
