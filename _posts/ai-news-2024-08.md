August was a month about reliability: a law that took effect, an API feature that guarantees the shape of model output, and a voice assistant you can interrupt.

## The EU AI Act enters into force (August 1)

The European Artificial Intelligence Act entered into force on 1 August 2024. It uses a risk-based approach with four tiers: minimal risk, specific transparency risk, high risk and unacceptable risk. Chatbots must tell users they are talking to a machine, and certain AI-generated content must be labelled. Obligations phase in over time: the Commission said the provisions on general purpose AI apply after 12 months.

## OpenAI introduces Structured Outputs in the API (August 6)

OpenAI introduced Structured Outputs in the API, which constrains model output to match a JSON Schema supplied by the developer. It went beyond JSON mode, which produced valid JSON but did not guarantee the response matched a particular schema. OpenAI named extracting structured data from unstructured inputs as one of the core uses of its API.

## Google rolls out Gemini Live (August 13)

At Made by Google, Google began rolling out Gemini Live to Gemini Advanced subscribers. It is a mobile conversational mode for free-flowing voice conversations in which you can interrupt mid-response or pause and return later.

## Why this month matters if you work with web data

Structured Outputs is the month's clearest signal for anyone who works with web data. Models are being asked to return data in an exact shape, and developers want proof it matches. NextRows applies the same idea to extraction: you describe the table in natural language, and schema validation makes sure that is what you get.
