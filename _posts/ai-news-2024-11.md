November's three developments shared one trait: each was released for others to build on, whether as code, as a visible reasoning process or as a protocol.

## Google DeepMind releases AlphaFold 3 code (November 11)

Google DeepMind published the AlphaFold 3 code on GitHub under a noncommercial license, Science reported, with model weights available to academics who complete a short application form. The model had been announced in May without code, which drew criticism from researchers.

## DeepSeek previews R1-Lite (November 20)

DeepSeek released DeepSeek-R1-Lite-Preview, a reasoning model. DeepSeek said it reached o1-preview-level performance on the AIME and MATH benchmarks and showed its thought process in real time, and that open-source models and an API were coming soon. TechCrunch described it as a Chinese lab's model to rival OpenAI's o1.

## Anthropic open-sources the Model Context Protocol (November 25)

Anthropic open-sourced the Model Context Protocol (MCP), an open standard for connecting AI assistants to the systems where data lives, including content repositories, business tools and development environments. Developers expose data through MCP servers or build applications that connect to them as MCP clients, replacing one-off integrations with a single protocol.

## Why this month matters if you work with web data

MCP is the clearest link to web data this month. Assistants need a standard way to reach data sources, and the data they reach needs a predictable shape. That shape is what NextRows produces: natural-language extraction checked against a schema.
