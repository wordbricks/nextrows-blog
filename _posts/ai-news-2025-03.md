March split into two stories. For developers, the scaffolding for production agents arrived. For everyone else, a single image feature showed how fast a capability can become a culture-wide moment.

## OpenAI opens the Responses API and Agents SDK (March 11)

OpenAI released the first building blocks of its agent platform: the Responses API, which combines chat completions with built-in tools - web search, file search and computer use - and the open-source Agents SDK for orchestrating multi-step, multi-agent workflows with tracing and guardrails. The message to developers: stop stitching prompts together; the scaffolding is now part of the platform.

## Google debuts Gemini 2.5, a thinking model (March 25)

Google introduced Gemini 2.5, its most intelligent model family, starting with Gemini 2.5 Pro Experimental. Reasoning is built in rather than bolted on: the model thinks through its response before answering. It debuted at the top of the LMArena leaderboard by a significant margin, with a one-million-token context window, and set the pattern for every Google release that followed in 2025.

## GPT-4o learns to draw, and the internet notices (March 25)

The same day, OpenAI rolled out native image generation in GPT-4o: images produced autoregressively by the model itself, with accurate text rendering, tight instruction following and the ability to transform uploaded photos. Within hours, feeds filled with portraits restyled as animation stills, and demand briefly overwhelmed OpenAI's capacity. It was the year's clearest demonstration that a capability, not a model name, is what goes viral.

## Why this month matters if you work with web data

March was builder month, and builders need raw material. Agent frameworks, built-in web tools and multimodal models all assume the underlying pages are readable and well-structured. When they are, an agent's output is trustworthy; when they are not, the scaffolding just automates the guessing.
